# 🌿 رابط کاربری وب سامانه فیتو (PhytoAgent Frontend)

رابط کاربری مدرن، تعاملی، واکنش‌گرا و کاملاً راست‌به‌چپ (**RTL**) برای سامانه هوشمند گیاه‌پزشک و مدیریت دوقلوی دیجیتال **PhytoAgent**. این بخش با استفاده از **Vue 3**، **TypeScript**، **Tailwind CSS** و **Pinia** توسعه داده شده است.

## 🌟 معرفی و نمای کلی

رابط کاربری **PhytoAgent Frontend** پل ارتباطی کاربر با سرور هوشمند پایتون و موتور گراف استدلال **LangGraph** است. این پنل به کاربران و پرورش‌دهندگان گیاهان آپارتمانی و گلخانه‌ای اجازه می‌دهد پرونده دوقلوی دیجیتال گیاهان خود را ثبت کنند، تاریخچه اقدامات مراقبتی را ثبت نمایند، علائم بیماری یا نیازهای تغذیه‌ای را همراه با عکس ارسال کرده و تقویم تغذیه دقیق ۴ هفته‌ای دریافت کنند.

## 🚀 ویژگی‌ها و ماژول‌های رابط کاربری

### ۱. داشبورد دوقلوی دیجیتال گیاهان (Digital Twin Garden Dashboard)

- **نمایش کارت‌های وضعیت سلامت:** دسته‌بندی بصری گیاهان بر اساس شاخص‌های سلامت (عالی، پایدار، نیازمند توجه، وضعیت بحرانی).
- **مدال ثبت گیاه جدید:** فرم کامل و استاندارد شامل نام، گونه گیاهی، واریته، بستر کشت (کوکوپیت، پیت‌ماس، لیکا، پرلیت، هیدروپونیک و ...)، نور دریافتی، رطوبت محیطی، نوع و اندازه گلدان و صفات مورفولوژیک (مانند ابلق / Variegated).
- **مدال مدیریت تاریخچه مراقبت (Care Event Logs):** ثبت و مشاهده رویدادهای آبیاری، کوددهی، سمپاشی، تعویض خاک، تعویض گلدان و هرس به همراه تاریخ و توضیحات.
- **انتقال مستقیم به چت:** امکان شروع مشاوره تخصصی گیاه‌پزشک با ارسال خودکار پرونده گیاه انتخابی به عنوان کانتکست به هوش مصنوعی.

### ۲. پنجره چت تشخیصی و استدلال گیاه‌پزشک (Diagnostic Chat & Triage)

- **چت بلادرنگ با موتور استدلال ایجنت:** ارتباط تعاملی با ایجنت LangGraph برای تریاژ علائم و بررسی‌های فیزیولوژیک.
- **بنر تریاژ ریسک هوشمند (Risk Triage Banner):** نمایش سطح ریسک گیاه در ۳ وضعیت:
  - 🔴 **اضطراری (High / Emergency):** خطر فوری پوسیدگی ریشه یا طغیان آفت با ارائه هشدارهای جلوگیری از کوددهی.
  - 🟡 **هشدار متوسط (Moderate Warning):** نیازمند اصلاح پارامترهای محیطی یا بررسی دقیق‌تر.
  - 🟢 **ایمن و پایدار (Safe / Stable):** شرایط مناسب جهت اجرای برنامه تغذیه روتین.
- **بارگذاری تصویر (Image Attachment):** امکان ارسال عکس برگ یا ساقه گیاه جهت تحلیل چندوجهی بینایی ماشین (Vision).
- **اسلات‌های ورودی سریع (Quick Slot Chips):** چیپ‌های کمکی برای پاسخ سریع به سوالات پرتکرار ایجنت (نور مستقیم/غیرمستقیم، رطوبت، زهکشی و ...).
- **کارت تقویم تغذیه ۴ هفته‌ای (4-Week Feeding Schedule Card):** نمایش ساختاریافته برنامه کودی هفته به هفته شامل:
  - فرمول دقیق NPK (مثلاً `20-20-20` یا `10-52-10` یا فرمولاسیون اختصاصی)
  - میزان مصرف (گرم در لیتر / سی‌سی)
  - حد مجاز هدایت الکتریکی (EC Target)
  - تعداد دفعات تکرار در ماه و توصیه‌های اگروونومی.

### ۳. کاوشگر پایگاه دانش گیاهی (Botanical KB Explorer)

- **جستجوی زنده در شناسنامه گونه‌ها:** جستجو بر اساس نام فارسی، علمی و سرده گیاه.
- **مشاهده پارامترهای اکولوژیک و فیزیولوژیک:** بازه تحمل EC، نیاز نوری (LUX)، دمای بهینه، درصد رطوبت و حساسیت‌های خاص.
- **قوانین تغذیه بر اساس بستر و صفات:** مشاهده فرمول‌های پایه خاک و اصلاحات مربوط به صفات ویژه (مانند کاهش نیتروژن در گیاهان ابلق برای حفظ تنوع رنگی).

### ۴. طراحی بصری، تایپوگرافی و تجربه کاربری (UI/UX)

- **RTL کامل و بومی:** چیدمان استاندارد فارسی با فونت استاندارد **Vazirmatn**.
- **پالت رنگی ارگانیک:** هارمونی رنگ‌های سبز زمردی (Emerald/Primary)، توسی تیره (Slate) و رنگ‌های اعتبارسنجی مدرن.
- **انیمیشن‌های نرم و ترنزیشن‌ها:** بازخورد تعاملی در لودینگ‌ها، جابه‌جایی تب‌ها و باز شدن مدال‌ها.

## ⚙️ پیکربندی پروکسی و اتصال به بک‌اند

فایل `vite.config.ts` به گونه‌ای تنظیم شده است که تمامی درخواست‌های ارسالی به مسیر `/api` را به صورت خودکار به سرور بک‌اند FastAPI هدایت (Proxy) می‌کند:

```typescript
// vite.config.ts
export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      "@": fileURLToPath(new URL("./src", import.meta.url)),
    },
  },
  server: {
    port: 5173,
    host: true,
    proxy: {
      "/api": {
        target: "http://localhost:8000", // آدرس سرور FastAPI
        changeOrigin: true,
      },
    },
  },
});
```

> [!TIP]
> اگر سرور FastAPI شما روی پورت دیگری (مثلاً `8011` یا `8012`) اجرا می‌شود، کافی است مقدار `target` در `vite.config.ts` را به پورت مربوطه (مثلاً `http://localhost:8011`) تغییر دهید و سرور Vite را مجدداً راه‌اندازی کنید.

## 🧠 معماری مدیریت وضعیت (Pinia Stores)

سامانه فرانت‌اند از ۳ استور مجزا برای جداسازی مسئولیت‌ها بهره می‌برد:

### ۱. `usePlantStore`

- نگهداری آرایه گیاهان کاربر (`plants`)
- بارگذاری داده‌ها از سرور (`fetchPlants`)
- افزودن گیاه جدید با اعتبارسنجی (`addPlant`)
- ثبت رویداد مراقبتی برای یک گیاه (`addCareEvent`)
- انتخاب گیاه فعال برای ارسال به ایجنت چت (`selectPlantForChat`)

### ۲. `useChatStore`

- نگهداری آرایه پیام‌های تاریخچه چت جاری (`messages`)
- ردیابی استیت ایجنت، بنر تریاژ ریسک (`riskTriage`) و تقویم تغذیه (`fourWeekSchedule`)
- مدیریت ارسال پیام به همراه تصویر پیوست به اندپوینت ایجنت (`sendMessage`)
- انتخاب اسلات‌های سریع (`handleSlotSelection`) و ریست کردن نشست گفت‌وگو

### ۳. `useKbStore`

- بارگذاری و کش کردن لیست گونه‌های گیاهی از پایگاه دانش (`fetchSpecies`)
- فیلتر و جستجوی لحظه‌ای براساس کلمات کلیدی (`searchQuery`)
- مدیریت گونه انتخاب‌شده برای نمایش جزئیات کامل اکولوژیک

## 🏗 راهنمای بیلد و استقرار پروداکشن

برای آماده‌سازی بسته نهایی جهت استقرار روی وب‌سرورهایی مانند **Nginx** یا **Caddy**:

### ۱. ایجاد بیلد بهینه

```bash
npm run build
```

این دستور ابتدا تایپ‌ها را بررسی کرده (`vue-tsc`) و سپس فایل‌های بهینه‌سازی‌شده، فشرده و Minify شده را در پوشه `dist/` ایجاد می‌کند.

### ۲. نمونه کانفیگ Nginx

```nginx
server {
    listen 80;
    server_name your-domain.com;

    root /path/to/plant-agent-gemini/frontend/dist;
    index index.html;

    # سرو فایل‌های استاتیک فرانت‌اند
    location / {
        try_files $uri $uri/ /index.html;
    }

    # هدایت درخواست‌های API به سرور FastAPI
    location /api/ {
        proxy_pass http://127.0.0.1:8000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## 💡 عیب‌یابی و نکات متداول (Troubleshooting)

### ۱. خطای `Network Error` یا عدم دریافت پاسخ از API

- مطمئن شوید سرور بک‌اند FastAPI در حال اجرا است (`uvicorn app.main:app --reload --port 8000`).
- اگر بک‌اند روی پورت دیگری در حال اجراست، بخش `proxy` در فایل `vite.config.ts` را به‌روزرسانی کنید.
- بررسی کنید که در کنسول مرورگر خطای CORS ثبت نشده باشد.

### ۲. پورت `5173` اشغال است (Port already in use)

- به صورت خودکار Vite تلاش می‌کند روی پورت بعدی (مانند `5174`) اجرا شود.
- همچنین می‌توانید در فایل `vite.config.ts` پورت دلخواه را تنظیم کنید:
  ```typescript
  server: {
    port: 3000,
  }
  ```

### ۳. بروز خطا در زمان `npm run build`

- اجرای دستور `npx vue-tsc --noEmit` را بررسی کنید تا در صورت وجود عدم تطابق در تایپ‌های TypeScript، خطای دقیق را مشاهده و برطرف فرمایید.

### ۴. پاک‌سازی کش در صورت عدم بارگذاری استایل‌ها یا فونت‌ها

```bash
rm -rf node_modules/.vite
npm run dev -- --force
```
